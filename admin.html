管理キーの設定

Supabase の旧形式 service_role キー(eyJ... で始まるJWT。ダッシュボードの API Keys → Legacy API keys タブ)を入力してください。新形式の sb_secret_... はSupabaseの仕様でブラウザから使用できません。キーはこの端末のブラウザにのみ保存され、送信先は自分の Supabase だけです。

店の削除(マップから除外)

除外した店はマップ・一覧に表示されなくなります(全端末、次回読み込み時に反映)。レビューは削除されず、復元すると元どおり表示されます。
